# 网站信息架构（第一期）

## 核心体验

网站被设计成一座可漫游的数字文学博物馆：访客先感受圣彼得堡冬夜，再选择一条线索深入，而不是被迫阅读一条很长的百科时间线。

## 第一版一级导航

| 区域 | 访客要解决的问题 | 内容形式 |
| --- | --- | --- |
| 首页 / 序厅 | 我正要进入怎样的世界？ | 黑白肖像、引语、沉浸式介绍 |
| 生平年表 | 他经历了什么？ | 可横向浏览的关键事件、城市坐标、书信 |
| 作品展厅 | 从哪一本书开始？ | 小说陈列卡、人物关系、章节摘录 |
| 思想索引 | 他的写作不断追问什么？ | 主题标签、引语、跨作品连接 |
| 手稿与档案 | 原作如何被写出来？ | 手稿影像、版本、注释、时间轴 |
| 阅读路径 | 我该怎样读？ | 面向新读者的三条策展路线 |

## 首期范围

先完成“序厅（首页）”以及三个下一步入口。之后优先建设《罪与罚》单部作品展厅，它能把城市、犯罪、贫困、心理与救赎自然连接起来。
